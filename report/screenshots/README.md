# Application screenshots

Drop the seven real application captures into this directory and rebuild the
report (`python report/build.py`); each file is embedded automatically in
Chapter 11 and listed in the List of Figures. Until a file exists the report
shows a clearly labelled placeholder frame instead — no fabricated imagery is
ever inserted.

| Expected file            | Screen captured                                              |
|--------------------------|--------------------------------------------------------------|
| `shot_login.png`         | Login / registration page                                    |
| `shot_upload.png`        | Resume upload page with the file picker                      |
| `shot_skills.png`        | Extracted skill profile with confidence and evidence         |
| `shot_jobs.png`          | Ranked job recommendations for the uploaded resume           |
| `shot_demand.png`        | Market demand analysis dashboard                             |
| `shot_gap.png`           | Skill-gap analysis with priority bands                       |
| `shot_roadmap.png`       | Generated personalised learning roadmap                      |

`.jpg` / `.jpeg` variants of the same base names are also accepted.
Capture them from a running instance (see `SETUP.md` at the repository root);
do not invent or mock screens.
